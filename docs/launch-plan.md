# Launch Plan

## 14-Day Lean Launch Plan

**Product build**
- Complete your own 10-Minute Offer Sprint
- Duplicate and fully build the Notion workspace (all 14 sections)
- Write and test all 30 prompts in ChatGPT
- Build the free mini-tool (Tally.so 5-question form + email delivery)
- Create the Offer Card template (Canva shareable image)
- Write the PDF Quick-Start Guide (10 pages max)
- Record a 3-minute walkthrough video of the workspace

**Sales infrastructure**
- Set up Gumroad or Lemon Squeezy (all 3 tiers)
- Write and upload the product description
- Set up affiliate program (20–30% commission)
- Build the landing page (Carrd / Framer / Webflow / this repo's static site)
- Apply the design system (colors, fonts, layout)
- Set up ConvertKit or Beehiiv email list
- Create the 5-email welcome sequence
- Connect checkout to email automation (tag buyer)
- Set up Day 2 and Day 7 automated emails

**Content launch**
- Film 3 TikTok/Reel videos before launch day
- Write and schedule 10 X/Twitter posts
- Design 3 Instagram carousels
- Build a waitlist page
- Post the waitlist announcement across platforms
- Set up a feedback form (Tally.so, 7 questions)
- Prepare the launch-day email
- Identify and DM 10 micro-creators for feedback/affiliate partnerships

**Post-launch**
- Collect first 3 testimonials using the Testimonial Request prompt
- Add real testimonials to the landing page
- Record a live demo video (Offer Sprint walkthrough)
- Post a Month 1 recap with real numbers
- Send the feedback survey to all buyers
- Plan a v1.1 update based on feedback

## Simple Experiment Plan (Post-Launch)

**Test 1 — Headline**
- Version A: "Turn One Skill Into a Sellable Offer This Weekend"
- Version B: "Your First Digital Offer. Built in One Weekend."
- Run for 7 days, compare CTR on the primary CTA.

**Test 2 — Price**
- Start at $29. After 50 sales, test $39.
- If conversion stays within 20% of baseline, keep $39.
- Never A/B test prices simultaneously without informing customers.

**Test 3 — Free preview**
- Test whether the free Notion "Offer Sprint" page increases paid conversions vs. a simple PDF worksheet.

**Test 4 — CTA copy**
- "Get Instant Access — $29" vs. "Build Your Offer This Weekend — $29"
- Run in email first (lower stakes), then apply the winner to the landing page.
